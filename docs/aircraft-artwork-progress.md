# 机型插画制作进度

## 已确认方向

- 每款从零独立生成，不沿用旧图的几何结构修细节，不以同一张图替代不同机型。
- 精致静态三维 CG 插画，白色无涂装、近侧视、机头向右、起落架收起、真实透明背景。统一光照与材质，不改变现有卡片布局。
- 制造商官方资料核对比例、驾驶舱、翼尖、尾翼、发动机数量与类型。插画不作为精确 CAD；无法确认的图留待处理。
- 使用 imagegen 技能和内置工具；不切换收费 API、不购买额度、不使用额度重置机会。

## 断点续做

- 本对话每小时续做任务：`续做机型插画`，automationId 为 `automation`，创建时状态 ACTIVE。完成全部目标并验证后停用该续做任务。
- 先核对本表和实际文件/映射，跳过已完成项。用户最终要求先生成所有剩余素材，全部核对后统一接入，而非逐款修改 App。
- 当前 16/16 已接入并通过定向验证。最后 8 款先全部独立生成到外层 `outputs/aircraft-remaining-batch-20261014/`；A320-200、B737 MAX 9 的首版舱门问题各从零重生成 v2，其余使用 v1。全部核对后统一复制资产、更新映射/pubspec/测试，只执行一轮整批测试与一次热重启。完整提示词、来源、版本取舍见 [最后八款生成记录](aircraft-artwork-batch-20261014.md)，manifest.json 保留原始输出路径及检查结果。
- 额度保护执行完毕：相关窗口剩余不高于 10% 时不继续生成；本批未触及阈值，未使用额度重置、购买额度或收费 API。目标已完成，无下一款待制作；续做任务 `automation` 已通过应用工具停用，返回状态 **PAUSED**。
- Codex 或生图工具报告限额时记录状态，不密集重试，下一次额度可用后继续。Codex 额度与生图额度可能不同，不保证同时恢复。
- 不重复改已确认插画，不生成未知机型，不扩展到涂装、实时 3D、发布或其他功能。
