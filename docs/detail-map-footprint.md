# 详细地图区域点亮

## 行为

- 仅详细底图的足迹模式显示：海外按完整国家/地区 Feature 点亮（保留群岛和内洞），国内按到访省级板块点亮，不整块点亮中国大陆。
- 复用现有已完成航班派生地点和手动足迹，不写入或修改用户记录；保留原有城市点击、删除入口和地图镜头逻辑。飞行模式、离线地图和地球渲染不改动。
- 暗夜绿使用 `detailFootprintDark` 冷绿色，冰川白使用 `detailFootprintLight` 清透蓝色；通过 Impeccable 的语义配色规范，保持色块弱于城市标记和文字。不添加描边、发光或循环动画。
- 区域填色位于基础陆地/植被之上，道路、边界、地名和用户地点之下。重绘详细底图水域作为遮罩，避免粗略轮廓覆盖海岸水面和湖泊。
- 缩放 0–4 保持概览浓度，4–8 逐步淡出，8 及以上隐藏区域色块；道路和地点保持原行为。这是概览点亮，不是街道级行政边界。

## 实现与保护

- `detail_map_footprint.dart` 缓存本地边界解码和包围盒索引；点位匹配、GeoJSON 序列化在 `compute` 中执行。记录列表不变时复用结果，手势帧不执行区域计算。
- 区域数据通过 `ff-regions` GeoJSON source 更新，不重新创建地图或调整镜头。只绘制 `isVisited` 且坐标有效的地点；多边形内洞和跨日期变更线匹配有测试覆盖。
- Native `onStyleLoaded` 可早于 `onMapCreated`，直接保存回调传入的 style，避免首次进入必须切换模式才能显示色块；异步结果使用 revision 校验，忽略旧视图结果。
- 本地边界失败时保留详细地图和地点，不阻止查看；外部 tile host 仍只接收底图请求，不上传个人地点集合。新增本地文件不改变既有来源许可与署名。

## 已知边界

国家资产为现有 Natural Earth 50m 简化轮廓，且没有 ISO 属性；当前按地点与几何包含关系匹配，不凭最近国家猜测。沿海机场、填海地或被简化掉的小岛可能没有区域命中，地点标记仍显示。世界级缩放也可能看到少量粗细海岸线差异，水域遮罩和放大淡出用于减轻这一问题；没有宣称精确街道级边界。后续可通过带可信行政区标识的更精细边界改善覆盖。

## 默认详细地图与自动备用（2026-10-15）

- Android/iOS/Web 的首页及全屏平面地图默认使用详细底图；不支持的桌面平台继续使用现有本地渲染器。首页和全屏工具栏删除手动详细/离线底图切换，不再维护独立选择状态。
- 本地数据和绘制组件全部保留：样式失败或 25 秒内未确认实际底图几何时自动显示备用。只留下失败原因和「重试」，成功后隐藏原「详细底图·试验」状态条；来源署名保留。首次加载的等待策略见下方防闪修正。
- 详细地图报告当前备用状态，用于保留本地镜头回报和全屏备用地图的航线播放条件。不新增后台轮询；网络恢复后由用户点击重试。地球与护照卡渲染不删除、不改写。
- 本轮按 Impeccable 的 distill 规范去除重复选择，保留必要的失败恢复能力。没有删除本地资产或用户航班记录。
- 验证：全项目 **374 项测试通过**，`flutter analyze --no-pub` 无问题；新增首页默认详细地图、全屏无切换入口/保留投影及重置、超时自动备用测试，既有失败重试测试改为验证没有手动离线按钮。
- Pixel Fold 模拟器最新代码热重启成功（1,986 ms）；截图确认首页详细底图默认显示、底图切换圆形按钮已移除、成功状态条已收起，署名保留。断网/超时流程由隔离测试覆盖，本轮未修改模拟器网络状态。
