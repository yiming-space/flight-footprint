# 免费执飞机型补全（开发版）

## 正式版安全开关（v1.3.0）

- 正式 release 构建默认关闭实验实时执飞机型查询（`FLIGHT_FOOTPRINT_ENABLE_LIVE_AIRCRAFT=false`），不请求 ADSB.lol `/v2/callsign/`，也不触发依赖实时观测的 ADSBdb 注册信息查询；`aircraftLookupAttempted` 保持 false，不显示“实时查询未匹配”等误导提示。
- ADSB.lol 常规 routeset 回退此前同样会访问其服务，现独立受 `FLIGHT_FOOTPRINT_ENABLE_ADSB_LOL_ROUTESET` 控制；release 默认 false，避免只关闭实时请求却仍访问尚未确认授权的 ADSB.lol 端点。
- 两个开关在 debug/profile 默认 true，保留开发验证能力；fixture 测试显式注入启用，不依赖构建模式。未完成维护者联系及数据许可确认前，发布命令不要传入开启这两个开关的 `--dart-define`。
- ADSBdb 常规航线补全及既有 adsb.im routeset 回退保留，原有匹配日期保护不变；机型仍可手动填写。关闭实验查询不等于所有自动补全都关闭，也不保证原常规来源每次命中。

## 使用方式

在记录/编辑飞行页面填写航司与航班号、确认起飞日期，点击原有“自动补全航班信息”。若查询到可信的机型，填入“更多信息 → 飞机机型”，显示观测来源及可用注册号；可手动修改。已有手填或已保存的机型不覆盖，保存仍由用户主动确认。

## 本轮接入

- 今日航班：将 IATA 航班号转换为可确认的 ICAO 呼号，查询 [ADSB.lol 公开实时接口](https://api.adsb.lol/docs) `/v2/callsign/{callsign}`，读取 `ac[].t/r/hex/flight/seen` 及响应 `now`。以本机本地日历日期判断“今日”，以 UTC 时间戳校验响应。无可靠 ICAO 候选则不猜呼号。
- `now` 兼容 Unix 秒/毫秒，与设备时钟差不超过 5 分钟；观测年龄 `seen` 必须在 0–120 秒且观测本地日期为今日。呼号必须精确匹配，有有效六位 Mode-S 或注册号。相同飞机可去重，冲突身份/机型或多架飞机则拒绝匹配。
- 有注册号或 Mode-S 但缺少型号时，调用 [ADSBdb 飞机接口](https://github.com/mrjackwills/adsbdb) `/v0/aircraft/{identifier}`。返回身份必须与观测飞机一致，不能拿另一个注册号的型号补全。
- 当用户已选机场与现有航线源返回机场冲突时，不合并实时机型；不根据飞机坐标猜航段。没有航线资料但有唯一实时飞机时，仅返回机型，不编造机场、起降时间或里程；仍需用户核对是否为本次航段。
- 机型代码本地归一，例如 B738 → B737-800、B38M → B737 MAX 8、A339 → A330-900NEO、E290 → E190-E2。A320、A321 等宽泛型号不会臆测 -200、LR 或其他后缀。
- 实时查询与原有航线补全并行，最多两个可确认的 ICAO 候选，每个新增请求最长 3 秒，缺型号时再做一次注册信息补全；无轮询、无后台定时查询、无付费 API 或密钥。原路线源仍按原超时/回退策略工作，因此整个操作时长并非保证 3 秒内结束。

## 日期与交互保护

- 过去、未来或未指定日期：不调用实时机型接口。常规航线可辅助填机场/时间，但无真实日期证明的机型和注册号不绑定到具体日期；time-only 被请求日期锚定后不算真实日期证明。
- 原来源带真实日期的机型，仅在起飞日期或明确 flightDate 与所选本地日历日一致时可保留，并标记为参考来源而非实时观测；不把相邻日时区容忍当成机型日期证据。
- 查询期间改变航班号、日期或机场：丢弃旧结果并提示重新查询；阻止按钮/键盘连续提交。用户在等待期间手填的机型仍不会被覆盖。
- 离线、404、超时、坏 JSON、过期响应、无匹配都不影响手动记录或原有航线补全。消息使用中英文、可换行，并作为可访问性 live region 提示。

## 免费能力边界与使用条款

这是一项尽力而为的实时观测补全，不是保证准确的排班或历史执飞数据库。未起飞、已结束且不再被观测、代码共享、同号多航段和接收网络覆盖不足时可能查不到；有机型也不表示已确认乘坐的是该架飞机。

本轮没有下载/建立 ADSB.lol 全量历史档案索引，没有添加面向用户的注册号输入框，没有批量补写数据库，没有创建订阅、发布或部署。注册号查询用于本轮实时观测缺型号时的内部补全。正式发行前需按 [ADSB.lol 官方接口条款](https://api.adsb.lol/docs) 联系维护者，并处理 ODbL 来源/数据许可要求；未来可能引入 API key，免费访问不代表永久服务保证。ADSBdb 的代码许可和其航线数据使用限制不同，不批量复制其航线库到项目或其他数据库。
