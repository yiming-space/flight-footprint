# 详细地图航线绘制优化（2026-10-15）

## 保留与改变

- 只改详细地图：无实际轨迹时采用 Mercator 平面上的二次 Bézier 示意弧线，沿有方向机场连线的法线弯曲，返程自然弯向另一侧。保留已有实际轨迹和跨日期变更线经度展开；地球/离线/护照卡绘制器及原大圆工具不变，不修改用户航班数据。
- 同方向、同机场经纬度、同轨迹的重复记录只画一条，Feature 保留次数及原始代表索引。A→B 与 B→A 是两条独立线；不同实际轨迹不会被当成同一条推测弧线合并。
- 往返示意弧线以机场连线为轴左右分开，不再靠两条平行线偏移，也不添加箭头。控制点偏移为连线长度的 0.32 倍、上限 0.75 投影弧度；24–64 段采样后缓存，极区限定在 Mercator 有效纬度内，不随缩放重算。它不是实测飞行路径或精确地理大圆。
- 实际轨迹不做弯曲变形；存在反向机场对时仍保留 1.3 逻辑像素显示偏移，仅用于区分重合线，不修改原轨迹数据。
- 普通线沿用原紫色：根据「航线太细」反馈，缩放 0/2/5/12 线宽为 1.0/1.15/1.4/1.65，连续插值；暗夜绿透明度 0.62、冰川白 0.9 不变。
- 远景标点缩放 0/2/5 的半径为 3.4/3.8/4.5，描边从 1.0 平滑恢复到 1.5；定位蓝点和点击查询范围不变。两个主题使用相同尺寸规律。
- 点击航线仅更新独立 `ff-route-selection` 源，选中线宽 2.05、透明度 1，仍保留其偏移。近邻查询返回多条线时按屏幕上偏移后的线段距离排名，而非总选最后绘制的一条；空白处/地点点击清除高亮。
- 点击继续使用原始有方向的 `MapRoute` 打开记录；原有记录查询区分去程/返程的逻辑不变。全屏详细地图接收完整原记录集，去重仅用于绘制；原全屏备用/地球的动画列表保留现有实现。

## 缓存与性能证据

- `DetailRouteCache` 复用相同记录列表的聚合 GeoJSON 和已序列化字符串；跨列表重建可复用最多 256 条几何。选择改变不重算坐标，足迹模式返回空航线源。
- `DetailSourceCache` 按 style 实例及源内容跳过未改变的源上传；更新定位点不会重复上传航线。新 style 重新上传，失败可重试，过期异步完成不会写回新 style 的缓存。
- 确定性 fixture：400 条重复往返记录，原大圆逐记录实现 400 次几何计算、334,731 个 JSON 字符；当前示意弧线聚合后 2 次几何计算、2,140 个字符。此为重复记录样本的工作量/体积对比，不是任意真实用户数据或设备 FPS 提升承诺。
- 按 Impeccable 的 optimize 规范，以明确的计算次数和上传内容验证优化，保留方向选择与记录完整性，不用动态重算换取装饰性曲线。
