# 机型图鉴与城市排行布局

## 机型图鉴

2026-10-16 用户可见名称统一为“已解锁机型”，数量“已解锁 N 种”；机型记录和家族插画规则保留。2026-10-18 按用户反馈恢复原先的透视叠卡，其他卡片统一收在主卡后方，不再在主卡下方单独露出预览；详情数字用主题主色/紫色区分次数与里程。统计口径见 [统计与到达状态记录](stats-visits-and-arrival-status.md)。

- 统计页入口与航司、城市、国家统计统一为卡片原位展开至独立页面、返回收回；iOS 保留原生交互返回，减少动态效果时使用短淡入淡出。图鉴内部卡组和机型详情转场保持不变。
- 默认按已完成航班的搭乘次数降序展示；提供全部、空客、波音、其他筛选。
- 透视机库式纵向叠卡，前卡完整展示，后卡缩小并沿 X 轴倾斜、露出型号；2026-10-18 利用底部留白将卡组适当下移，后方最多露出四张卡片，不在主卡下方单独摆放卡片。宽屏保持最大 700 宽的阅读列。不加描边和分割线，保留主题色。
- 航空收藏海报卡：精确型号、制造商、低对比的真实机型家族背景字、完整侧视插画与底部次数/里程数据组；不编造参数，不改变 PNG 比例。减少动态效果、较大字号或高度不足时回退可滚动单列，卡片自然增高，文字可换行。
- 点击整卡原地上下翻转并展开为独立机型详情页，包含插画、首次/最近搭乘日期及真实航班列表；航班 ID 去重并按出发时间倒序，只读，不修改航班记录。
- 详情页上半区采用收藏展示层级：型号与制造商紧密分组，飞机保持完整轮廓、不改 PNG，展示框比例由 2 调整为 2.6 以收紧上下留白；不再显示“机型风格示意”文案。次数/里程及首次/最近搭乘共用双列锚点，数字突出、单位弱化；内容宽度不足 320 或字号倍率达到 1.5 时自动改为自然增高单列。保留部分里程/未记录提示、无障碍标签及下方完整航班卡，不添加描边、分割线或额外卡片容器。
- 型号归一仅处理大小写、空白及可确认的制造商前缀；不同具体型号、MAX/NEO 变体不合并。航班 ID 去重。
- 里程只累计有效有限非负数；缺失和部分记录分别标记，不将缺失里程当成完整累计。

### 透视叠卡动效（2026-10-14）

- 竖向拖动直接控制连续位置，松手以当前位置和速度进入弹簧；可随时再次拖动和反向。快甩单次最多跨三张。
- 多机型卡组首尾循环：末张继续上滑进入首张，首张下滑进入末张，保留键盘与语义增减。机型页移除排序说明、底部上下箭头和页码（通用卡组的 `showControls` 默认仍为 true）。连续虚拟位置映射回真实机型索引，跨首尾不重置动画；附近最多六张（主卡、四张后卡及一张渐入预载）、仅一张可交互及使用 Hero。只有一款时不循环，辅助列表保持有限长度，无自动轮播。
- 当前启用 `cycleDepth: true`、`recycleArc: false`，关闭 `flipInPlace`：前卡随上滑向上抽出，后卡从拖动开始同步补位；前卡完全离开卡组裁切区域后才改变绘制层级，再缩小收进牌堆末尾。退出阶段保持正面和不透明，不使用中途淡出交接；没有 90 度翻面、放大预备动作或横向甩动。正反向拖动复用同一连续位置函数，不通过选中索引硬切层级。
- 旋转只保留浅角度透视，不绘制镜像背面；停稳时主卡归零，飞机不独立翻转。额外预载一张远卡并逐渐露出；高度不足时回退普通列表。
- 首次进入时卡组用 450 ms 从紧凑状态展开，内容始终可见；开始拖动或按上下按钮时立即结束入场，不等待动画。筛选和详情返回不重播，单卡和减少动态效果时跳过。
- 飞机以独立、可中断的弹簧跟随卡组，保留重新定向前的速度，最大横向 10/纵向 5 逻辑像素视差；卡片直接跟手，飞机柔和落稳到精确零偏移，停止后无循环或空转 ticker。不旋转或拉伸素材。
- 只构建附近最多六张，使用已有缓存图片和 RepaintBoundary，无实时 3D、模糊或新依赖。
- 只有当前卡片可点击和被辅助功能朗读，另提供 48dp 上下切换按钮、位置计数及键盘/语义增减操作。
- 筛选分别记住已选机型；详情返回保持当前卡。弹簧途中点击会中止旧目标并吸附到当前机型。
- 点击整卡时从当前卡片实际位置翻转并扩展至全屏（进入 460 ms、返回 420 ms），正反面只在侧立位置交接，期间关闭独立插画 Hero，避免两套动画争抢。源卡在 Navigator 首帧离屏测量时仍显示，覆盖层可绘制后才隐藏；返回接近落位时提前恢复到覆盖层下方，避免移除覆盖层后才恢复造成空帧。重复点击保护保留至返回结束。详情内容始终使用真实页面，不截屏替代。iOS 保留原生页面转场和交互式侧滑返回。
- 减少动态效果时详情切换为 120 ms 淡入淡出；卡片按下时提供 80 ms 的轻微缩放反馈，拖动取消按压。
- 紧凑卡数据区增加 4 逻辑像素的字号缩放余量（卡片预算同步从 176 改为 180）；点击展开通过 `frontSize` 保留原卡未变换的布局尺寸，`sourceRect` 仅确定屏幕位置和过渡目标，避免按透视压缩后的尺寸重新排版造成底部溢出。
- `disableAnimations` 或 `accessibleNavigation` 开启时使用普通列表并关闭插画 Hero；大字号和矮屏也回退列表，避免固定高度裁切。

## 城市胶囊溢出修复

`AirlineRankingRow.containContentInFill` 默认关闭，仅城市排行打开。城市列表使用同一视口和字号下的共同可读基准宽度，再让剩余宽度随次数变化；先确定条长，再按实际 TextScaler、locale 测量内部文字并换行或省略。

- 排名、城市、国家和次数都留在彩色胶囊内。
- 长城市名最多两行，Tooltip 与语义保留完整名称。
- 城市胶囊长度不是严格百分比刻度；真实起降次数及排序不变。
- 同次数必须同长度，较多次数必须更长；城市名、国家名和排名不能撑长单独一条。
- 航司排行保留原有严格次数比例、品牌配色和无底槽行为。
