# 个人飞行记忆

统计页在飞行护照后增加年份明确的飞行记忆。默认展示当前年，选择护照年份时同步查看该年；首次认定始终比较完整已完成航班历史，避免筛选后把旧经历当成新经历。

- 新抵达城市：国家与规范城市名识别，优先真实到达时间。历史出发也作为已到访证据，返回常住城市不误算新城市。多机场同城市合并；未知机场不猜测。
- 最常飞航线：该年已完成航班中，同一IATA机场对的两个方向合并；至少两段才展示。按段数计数，不声称往返次数。
- 首次记录机型：复用现有机型规范化，完整历史最早一条属于选定年份才算新机型；未知不推测，NEO/MAX等不混同。
- 每项可以进入对应记录页。城市与机型展示首次记录的航班，常飞航线展示该年这一机场对的所有航班；没有数据的项目不可点击。
- 同ID记录去重，未完成航班不参与；首次仅基于已保存的飞行记录，历史不全时不代表人生第一次。

15项新增数据与界面测试通过，另有既有里程碑与启动回归通过；320与900宽、英文2倍字号无溢出。


## 探索页横向卡组

按用户反馈，把统计页独立飞行记忆移至探索世界顶部，与最远足迹组成四张横向卡片：最远足迹、新抵达城市、最常飞航线、首次记录机型。保留最远足迹的原有城市、国旗、连线、距离、日期与常住城市编辑。每张记忆卡突出单个主题，点击进入原有对应航班记录页；无记录的卡片解释空状态且不可点击。

卡组支持原生水平滑动及前后按钮，显示当前主题和页码；以实际内容自然高度测量，切页时调整容器高度，未锁死卡片高度。非当前页关闭Ticker、交互和读屏内容，减少动态效果时直接切页。统计页的原重复汇总卡移除；完整历史首次认定和年份传递保留。


## 统一尺寸与精简指示

四张卡片严格沿用第一张最远足迹的实际宽高，切换时保持相同尺寸；首卡在宽度、字号或数据变化时重新测量，其他卡同步使用同一尺寸。长内容在卡片内部可滚动，不缩小系统字号。底部只留四个可点击圆点，移除左右箭头、主题名和数字页码；移除所有记忆卡的“查看对应航班”文字及箭头，整卡点击查看记录仍保留。

12项切卡与个人记忆界面测试通过，并覆盖窗口变宽、首卡高度变更后保持选中页和统一尺寸；原探索页相关回归通过。
