# 首页自动检查更新

- AppShell 首次显示首页后，复用「我的」页面现有的更新服务和提示／下载流程静默检查，无需先切换到「我的」。
- 首页与「我的」共享同一检查状态，普通切换标签不重复请求或弹出同一版本；手动「检查更新」仍可主动重查。
- 自动检查仅在首页／「我的」且主路由仍在最前时展示新版本提示；无新版本、未配置或网络失败不弹提示，不阻塞本地功能。
- 如果请求返回时已进入其他标签或覆盖路由，不覆盖用户当前操作；下一次进入允许提示的标签可重新检查。已释放的页面不显示提示，不调用 setState。
- GitHub manifest、release API 回退、版本比较与平台安装包下载逻辑保持不变。本次未修改版本号、远程 update.json、GitHub release 或用户记录。
